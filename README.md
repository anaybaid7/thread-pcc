# THREAD

**Traceable Health Risk Escalation & Action Detection** — a care-team copilot that reconstructs how a resident's
health concern evolves across measurements, progress notes, interventions and shift handovers, and shows when the
evidence still doesn't establish that the concern has been resolved.

Built for the PointClickCare **Catch It Early** challenge at Hack the Valley. All data is synthetic.

```bash
make setup   # Python venv + web dependencies
make dev     # API on :8000, app on http://localhost:3000
make test
```
